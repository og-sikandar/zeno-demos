Confirm the fence line, elevations, and gate locations

We verify the exact run of the fence, note any slope/grade changes, and confirm where gates will sit so everything lines up cleanly.

Prepare the area and mark post locations

We mark post positions and gate openings, accounting for corners, transitions, and clearances to avoid surprises once work starts.

Set posts and verify alignment

Posts are set in their planned locations, then checked for plumb and consistent spacing so the fence stays straight and stable.

Install panels/sections and check level/spacing

We install the iron panels and continuously check height, level, and spacing so lines stay uniform from start to finish.

Hang gates and install hardware

Gates are mounted with hinges and latches, then positioned so they fit the opening properly and operate without binding.

Adjust swing and latch points for smooth operation

We fine-tune hinge tension and latch alignment so the gate swings smoothly, closes cleanly, and latches securely.

We clear the work area and do a final walkthrough to confirm alignment, gate function, and finish details before calling it complete.
